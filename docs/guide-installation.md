# Guide d'Installation : PC SERVEUR & POSTES CLIENTS

## Étape 1 : Installation sur le PC Serveur Principal

1. Exécutez l'installateur :
   `Gestion_Centre_Deuxieme_Chance_Setup.exe`
2. L'assistant crée le répertoire `C:\GestionDeuxiemeChance`, configure le pare-feu Windows pour le port 3000, et crée les raccourcis Bureau et Menu Démarrer.
3. Lancez l'application via le raccourci **Gestion Centre Deuxième Chance**.
4. Au démarrage, la fenêtre affiche :
   - L'état : 🟢 **Serveur Actif**
   - L'adresse IP locale détectée (ex : `http://192.168.1.100:3000`)
   - Le QR Code pour les smartphones.

## Étape 2 : Connexion des autres PC du Centre
Les autres PC n'ont pas besoin d'installer de base de données.
Ouvrez simplement Google Chrome, Microsoft Edge ou Firefox et tapez l'adresse du serveur :
`http://192.168.1.100:3000`

## Étape 3 : Connexion des Smartphones Android
1. Connectez le smartphone au Wi-Fi du centre.
2. Ouvrez l'application Android `Gestion_Centre_Deuxieme_Chance.apk` (ou l'appareil photo/navigateur).
3. Scannez le QR Code affiché sur l'écran du PC serveur.
4. L'application mémorise l'adresse et se connecte automatiquement.
